# Google Drive API 設定手順書

本プロジェクトでGoogle Drive連携を行うために必要な `credentials.json` を取得する手順です。
Google Cloud Consoleを使用します。

## 1. プロジェクトの作成

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスします。
2. 左上のプロジェクト選択プルダウンをクリックし、「**新しいプロジェクト**」を選択します。
3. プロジェクト名（例: `SunoAutomation`）を入力し、「**作成**」をクリックします。
4. 通知エリアなどから、作成したプロジェクトを選択（切り替え）します。

## 2. Google Drive API の有効化

1. 左側メニューから **「APIとサービス」 > 「ライブラリ」** を選択します。
2. 検索バーに `Google Drive API` と入力して検索します。
3. 検索結果から **Google Drive API** をクリックします。
4. 「**有効にする**」ボタンをクリックします。

## 3. OAuth 同意画面の設定

APIを利用するための初期設定（同意画面の作成）を行います。

1. 左側メニューから **「APIとサービス」 > 「OAuth 同意画面」** を選択します。
2. **User Type** で **「外部 (External)」** を選択し、「**作成**」をクリックします。
   > ※ 個人のGmailアカウントを使用する場合は「外部」になります。
3. **アプリ情報**を入力します（必須項目のみでOK）。
   - **アプリ名**: `SunoAuto` など
   - **ユーザーサポートメール**: 自分のメールアドレス
   - **デベロッパーの連絡先情報**: 自分のメールアドレス
4. 「保存して次へ」をクリックします。
5. **スコープ**画面は何も変更せず、「保存して次へ」をクリックします。
6. **テストユーザー**画面で重要設定を行います。
   - 「**ADD USERS**」をクリックし、**自分のGmailアドレス**を入力・追加します。
   - **【重要】** これを行わないと、認証時に「アクセスをブロック: アプリはGoogleの審査プロセスを完了していません（エラー 403）」が表示され、ログインできません。必ず自分がログインしようとしているGmailアドレスを追加してください。
7. 「保存して次へ」をクリックし、概要画面で「ダッシュボードに戻る」をクリックします。

## 4. 認証情報 (Credentials) の作成

実際にプログラムで使用する鍵ファイルを作成します。

1. 左側メニューから **「APIとサービス」 > 「認証情報」** を選択します。
2. 上部の **「+ 認証情報を作成」** をクリックし、**「OAuth クライアントID」** を選択します。
3. **アプリケーションの種類**: **「デスクトップ アプリ」** を選択します。
4. **名前**: `SunoBotClient` など（そのままでもOK）を入力し、「**作成**」をクリックします。
5. 「OAuth クライアントを作成しました」というポップアップが表示されます。
6. **「JSONをダウンロード」**（下矢印のアイコン）をクリックし、ファイルをダウンロードします。

## 5. ファイルの配置

1. ダウンロードしたJSONファイル（`client_secret_xxxx.json` のような長い名前）を、プロジェクトのルートフォルダに移動します。
   - 配置場所: `c:/Users/kuseg/りゅうき/antigravity/06_auto_suno/`
2. ファイル名を **`credentials.json`** に変更します。

## 6. 確認

コマンドプロンプトで以下を確認してください。

```bash
ls credentials.json
```

ファイルが存在すれば準備完了です。次回 `python -m src.main` を実行すると、ブラウザが立ち上がり、Googleへのログインと許可を求められます。許可すると `token.json` が生成され、次回以降は自動でログインされます。
