## 5\. プロンプト定義（AIへの指示）

解析精度を担保するため、以下の指示（System Instruction）をAPI送信時に付与する。

> **指示内容：**
> 与えられたレシート画像を解析し、以下のJSONフォーマットで回答してください。
>
>   * 日本の消費税率（8%・10%）を厳密に区別すること。
>   * レシート上の「\*」「※」「(軽)」等の記号がある項目は消費税8%として計算してください。
>   * 金額が見えにくい場合は、周辺の数値から論理的に推測せず、不明な場合は null を返してください。
>
> **出力形式：**
>
> ```json
> {
>   "date": "YYYY/MM/DD",
>   "store": "店舗名",
>   "total_amount": 0,
>   "tax_8_amount": 0,
>   "tax_10_amount": 0
> }
> ```

## 6\. 非機能要件

### 6.1 セキュリティ・プライバシー

  * **API利用:** Google AI Studioの「Free Tier（無料プラン）」を使用する。
  * **データ保護:** 無料枠では入力データが学習に利用される可能性があることを承知の上で運用する。秘匿性の高いレシート（個人名が記載された領収書等）は対象外とする運用ルールを設ける。
  * **認証:** APIキーはGASの「スクリプトプロパティ」に保存し、コード内にハードコーディングしない。

### 6.2 運用・保守

  * **エラーハンドリング:** 画像が不鮮明で解析不能な場合、エラーログをシートに記載し、画像を「要再確認フォルダ」に移動させる。
  * **無料枠の管理:** 1分あたりのリクエスト数（RPM）制限を考慮し、大量のレシートを一度に処理する場合は、GAS側で `Utilities.sleep()` 等の遅延処理を入れる。

## 7\. 将来的な拡張性

  * **カテゴリ自動分類:** 商品名から「食費」「日用品」等のカテゴリをAIに自動判定させる機能。
  * **予算比較:** スプレッドシート上の月間予算シートと突合し、予算超過を通知する機能。
